Cookie Policy

This site sets exactly two cookies, both first-party:

  • visitor_id — a random anonymous identifier, created the first time you react to a blog post. It exists only so a like can be un-liked and so one visitor counts once per reaction. It is never linked to your name, address, or anything else about you. Expires after one year.
  • admin_session — set only for the site owner after logging into the admin panel. If you're not the owner, you'll never receive it.

There are no analytics cookies, no advertising cookies, and no third-party trackers. Session storage is used to count a page view once per visit.

Privacy Policy

What this site stores, all of it on its own server:

  • Things you write — comments, blog reactions, and messages you submit through the message boxes, together with the name and (optional) contact you provide. Messages are only shown publicly after manual approval, and contact details are never shown publicly.
  • Anonymous counters — page views, path choices, resume opens, shares. These are plain counts with a coarse traffic source (e.g. "LinkedIn", "Direct"); no IP addresses or identifiers are kept with them.

Nothing is sold or shared with third parties. Fonts and 3D libraries are fetched from CDNs (Google Fonts, jsDelivr, Cloudflare), which see your IP address as part of serving those files, as with any website using them.

To have a comment or message you wrote removed, use the contact form on any path and describe what to remove — it will be deleted.
