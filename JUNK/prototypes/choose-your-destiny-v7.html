Record I

Architecture

This portfolio is a single HTML file. No framework. No bundler. No node_modules. Three.js from a CDN, Web Audio API, and a lot of careful thinking about what actually matters.

The world renders, the audio breathes, the objects animate — all from scratch, all in one file you can open in any browser.

Record III

The Stack

  • Three.js r128 — cinematic 3D world
  • UnrealBloomPass + film grain + vignette — post-processing pipeline
  • Web Audio API — procedural ambient sound, no audio files
  • GLSL custom vertex + fragment shaders — stars, aura particles, fog
  • ACESFilmic tone mapping — colour grading
  • CSS transitions + vanilla JS — everything else
Record IV

The Objects

The castle, scroll, sword, and gold pile are placeholder geometries — BoxGeometry, CylinderGeometry, SphereGeometry assembled by hand. Each has a marked GLTF slot in the source.

Swap in a real model from poly.pizza or sketchfab.com, call registerGroup(), done. The hover glow, emissive animation, and aura particles all follow automatically.

Record V

The World Details

  • Fog colour shifts per-hover via THREE.Color.lerp()
  • Each object has a shader-based aura particle system
  • Object animations: sword sways, scroll bobs, gold glitters, flag waves
  • Cinematic camera intro sweep on world load
  • Moon falls with physics. You found out.
  • Dynamic world prompt text reacts to hover state
  • Mobile touch support + ESC key navigation
