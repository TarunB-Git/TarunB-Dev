# Quarantined prototypes and source drops

These files are intentionally excluded from the live site. They are retained
only as recoverable references for earlier ideas or future asset work.

- `prototypes/`: superseded standalone HTML/JavaScript experiments and the old
  Three.js world implementation.
- `source-models/`: duplicate source drops and the unrigged character concept.
- `imported-ui/`: original copies of the two UI icons; the live copies are in
  `static/assets/ui/`.

The production model sources used by `npm run models:optimize` remain in
`reference_assets/original_models/` so attribution and rebuilds continue to work.
